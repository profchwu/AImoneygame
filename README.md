# 願望理財屋 · 真 3D 理財機關版

兩個場景：午夜玩具商廊、月光溫室。小學生可操作六座機關：生活供電盤、找零齒輪箱、四週儲蓄橋、暴雨緊急閘、廣告查證線路、晴雨種子引擎。這些是金額配置、找零組合、週期安排、證據配對和情境模擬；不再使用三選一題目。

每座機關的線索在操作台上，通過後會升起對應實體閘門。完成三座機關後，解開該關主題 KEY 寶箱，到出口按 E 開門。保留兩關分數、首次與最後作答達成度和探索嘗試次數。被追上保留已解鎖機關與 KEY。每座機關 90 秒，錯誤啟動扣 4 秒；主題題目按原有評分規則計分。速度本身不計分。

操作：WASD／方向鍵、點地面行走、空白跳躍、Shift 衝刺、Ctrl 在高櫃旁躲藏、E 互動、Esc 暫停、R 重試、M 音效。觸控提供按鈕。機關上的 ＋／− 與拉桿支援鍵盤焦點及觸控。

美術：Three.js WebGL 真 3D 透視場景，統一地板、木箱、櫃子的材質；實體模型、深度遮擋、投影陰影。v6 恢復原深綠針織斗篷主角：使用既有站立圖與六格走路圖，嵌入 3D 世界，保留深度遮擋、輪廓投影與腳底接地陰影。主角是圖像角色，不是完整 3D 網格；巡夜者仍由 Blender GLB 匯入。新版怪物來源 source_models/warden3d.blend。這是風格化 3D 美術，不是原先參考圖的預渲染電影品質。舊版 2.5D 素材保留供回溯，但執行入口使用 stage3d.js。

不使用外部 CDN、登入或後端；紀錄存在本機瀏覽器 wish-house-finance-v5，舊版紀錄不刪除。所有教學金額都是虛構模擬，不是投資建議。Three.js 採 MIT 授權。

本機：node web/serve.mjs。測試：node --test web/tests/*.test.mjs。發布：python tools/package_web.py，將 builds/github-pages 檔案上傳 GitHub main 根目錄，Pages 自動部署。Netlify 也可直接使用同一資料夾，無建置指令。退版可在 GitHub 恢復上一個發布 commit 0a5e060。
